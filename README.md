# 로또 (Lotto) 미션

## 구현할 기능 목록

### 1. 초기 설정 및 입력

* **1.1 로또 구입 금액 입력 및 유효성 검사**
    * [✅] 숫자 형식 검사
    * [✅] `1,000원 단위` 유효성 검사
    * [✅] `IllegalArgumentException` 발생 및 재입력 처리
* **1.2 로또 발행 수량 계산**
    * [✅] 구입 금액으로 구매 가능한 로또 수량 계산
* **1.3 당첨 번호 입력 및 유효성 검사**
    * [✅] 쉼표(`,`) 구분된 6개 번호 입력 처리
    * [✅] 1~45 범위 검사
    * [✅] 6개 번호 중복 검사 및 숫자 형식 검사
    * [✅] `IllegalArgumentException` 발생 및 재입력 처리
* **1.4 보너스 번호 입력 및 유효성 검사**
    * [✅] 1개 번호 입력 처리
    * [✅] 1~45 범위 검사
    * [✅] 당첨 번호와의 중복 검사
    * [✅] `IllegalArgumentException` 발생 및 재입력 처리

### 2. 로또 발행 및 출력

* **2.1 로또 번호 생성**
    * [✅] `Randoms.pickUniqueNumbersInRange`를 사용하여 중복 없는 1~45 사이 6개 번호 생성
* **2.2 발행 결과 출력**
    * [✅] `N개를 구매했습니다.` 출력
    * [✅] 각 로또 번호를 **오름차순** 정렬하여 출력

### 3. 당첨 확인 및 결과 처리

* **3.1 `Rank` Enum 정의 및 활용**
    * [ ] 매칭 개수, 보너스 일치 여부, 당첨 금액을 포함한 5개 등수 정의
* **3.2 당첨 등수 판별 로직**
    * [ ] 사용자의 로또와 당첨 번호를 비교하여 매칭 개수 및 보너스 일치 여부 확인
    * [ ] 당첨 확인 결과를 **`Rank` Enum**으로 반환
* **3.3 당첨 통계 집계**
    * [ ] 등수(`Rank`)별 당첨 개수를 집계 및 관리

### 4. 최종 출력

* **4.1 당첨 통계 출력 포맷**
    * [ ] 당첨 통계를 요구된 포맷(`3개 일치 (5,000원) - 1개` 등)으로 출력
* **4.2 수익률 계산 및 출력**
    * [ ] 총 상금 대비 구입 금액의 수익률 계산
    * [ ] 수익률을 **소수점 둘째 자리에서 반올림**하여 `%` 형식으로 출력
